Como conectar

Peça ao seu assistente: configure um conector MCP com este link e cole o link. Qualquer assistente que aceite conectores MCP remotos (HTTP) funciona.

  2. Claude Code: claude mcp add --transport http controle-gastos <link>

Depois, mande o extrato do banco e peça para adicionar sem repetir. Mais em Como usar.
